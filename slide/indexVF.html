Backstage

TechDocs

Plugin officiel Backstage

Génère une documentation statique à partir de Markdown

Docs versionnées dans le repo du composant

Architecture

Intégration — Structure d’un Catalogue Backstage

``` service-repo/. │ ├─ src/ ├─ docs/ # Dossier TechDocs │ ├─ mkdocs.yml │ ├─ index.md │ ├─ how-it-works.md │ └─ images/ └─ catalog-info.yaml # Déclaration du composant + lien vers doc ```

Démo — Scénario rapide (6 min)

Objectif : montrer de l'import d'un composant -> visualiser TechDocs dans Backstage -> modifier et re-générer

Fichiers-clés (exemples)

# mkdocs.yml
site_name: Mon Service
nav:
  - Accueil: index.md
  - API: api.md

# catalog-info.yaml (extrait)
metadata:
  name: mon-service
  annotations:
    backstage.io/techdocs-ref: dir:./docs

Commandes utiles (CI & local)

# Exemple local / git
git clone git@github.com:org/mon-service.git
cd mon-service
# éditer docs/index.md
git add docs/index.md
git commit -m "Ajout intro TechDocs"
git push

# Si vous utilisez Backstage local
cd backstage
yarn dev

# Extrait CI (pseudo)
- name: Build TechDocs
  run: mkdocs build -d site
- name: Upload to S3
  run: aws s3 sync site/ s3://bucket/mon-service/

Bénéfices & bonnes pratiques

  • Docs versionnées avec le code
  • Visibilité centralisée pour les équipes
  • Automatisation via CI/CD
  • Templates MkDocs partagés et revue PR pour docs
